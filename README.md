# BookMyShow Database Design

MySQL database design for a simplified BookMyShow movie listing
system.

## Features

- Theatre management
- Screen management
- Movie management
- Movie show scheduling
- Show lookup by theatre and date
- Normalized database design
- Sample data

## Entities

- Theatre
- Screen
- Movie
- Show
